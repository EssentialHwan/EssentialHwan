# 개발 결정 기록 (Decision Log)

시간순 주요 결정. 각 결정의 "왜"를 남겨 나중에 뒤집지 않도록 한다.

## 기획 확정
- **핵심 재미 = 정보 비대칭 해소**: 숨겨진 취향(Truth)을 행동 관찰로 역추론. "돈"이 아니라 "이해"를 판다.
- **Truth ↔ Observed 물리적 분리**: 세이브·UI에 Truth 없음. 오추론 유도가 재미의 일부.

## 검증 후 수정 (P1~P10)
- **P1** fallback 단서 weight 0.5 + cap 2 → 가짜 가설("일반석 선호") 차단. *왜: fallback이 오추론 재료로 쌓여 좌절 유발하던 문제.*
- **P2** 분위기를 독립 관찰 축에서 제외 → 좌석/시설 만족 승수(MVP는 무영향). *왜: 초반에 죽은 축 + 인지 부하. 관찰 3축으로 단순화.*
- **P3** 카페 성장에 OR 대체 경로. *왜: 관찰 실패 시 골드가 넘쳐도 영구 데드락 위험.*
- **P4** 추론 4단계(?→…→★→✓). *왜: "자동 Confirmed"와 "플레이어 기록" 규칙 충돌 해소.*
- **P5** 만족도 satisfactionHistory 단일 소스. *왜: 3곳 중복 필드 불일치 위험.*
- **P6** SeatSelectionScore/SeatSatisfactionBonus 명명 분리. *왜: 동명이개념 혼동.*
- **P7** maxSitDuration + 회전율 압박 제거. *왜: "빨리 내보내기"가 관찰 게임 역행.*
- **P8** MVP 축소(관계·상황·MoveSeat/Social 제외). *왜: 코어 무관 + 개발기간.*
- **P9** 발견 성공 연출. *왜: 첫 세션 인과 학습.*
- **P10** 음식 favorite만(MVP), 계열은 정식. *왜: 초기 구분 난이도 대비 비용.*

## 주방 1인칭 시점 (2026-10-18)
- **결정**: 원탭 조리를 '주방 1인칭 카운터 시점'으로 표현. 하단 40% = 카운터·기구 5종·바리스타 고양이 앞발 2개, 상단 60% = 카메라를 뒤로 뺀 실제 홀(손님 실시간).
- **왜**: 직접 만드는 손맛·스크린샷 임팩트는 얻되, 조리 미니게임(삭제 항목)처럼 관찰을 빼앗지 않도록 '누르고 기다리는 동안 손님을 본다' 구조. 3D 전환 없이 2D 레이어로 구현(1인 개발 범위).
- **규칙**: 기구를 누르면 그 기구로 만드는 가장 오래된 주문을 조리 → cookTime 후 완성 → 완성품(기구) 클릭 = 서빙. 기다림 45초 초과 시 불만 퇴장.
- 기구↔메뉴: 커피머신(아메리카노) · 주전자(우유·캣닢차) · 오븐(생선케이크·푸딩) · 도마(참치샌드·파르페) · 그릴(구운생선).
- 고양이 모션 추가: 주문(앞발 흔들기) · 그루밍 · 기지개(자리 뜰 때). 총 10프레임.

## 고해상도 고양이 리그 + 행동 클립 (2026-10-18)

## 귀여운 비율 + 상호작용(쓰다듬기·고양이끼리) (2026-10-18)
- **아트**: 72×60 캔버스, 큰 머리(r12)·짧은 몸/다리, 3/4 얼굴(두 눈 5×6 + 반짝임, ω 입, 볼터치), 표정(웃음/화남/놀람/졸림). 깨짐 수정: 앉기 귀 잘림, 기지개 머리 잘림, 그루밍 앞발이 머리 뒤에 숨음, 잠 포즈 코가 바닥에 묻힘, 얼룩이 움직일 때 미끄러짐(무늬 좌표를 부위 기준으로), 꼬리 줄무늬 깨짐.
- **쓰다듬기(클릭)**: 기질(첫 성격 태그) → 애교(배 보이기·부비·골골) / 장난(덮치기) / 킁킁 / 낯가림(움찔, 단골 2단계부터 허락) / 변덕(좋다가 냥펀치) / 까칠(하악, 단골 3단계면 킁킁). *왜: '알아가는 재미'를 취향 3축 밖의 즉각적인 손맛으로 확장.*
  - 관찰 결과만 저장(touchSeen) → 도감 '손길' 칸. 기질(Truth)은 저장 안 함.
  - 방문 중 기분 ±2 × touchPerMood(5) 만큼 만족도 반영 → 까칠한 애를 계속 건드리면 팁이 줄어듦. **밸런스 가정값**.
- **고양이끼리**: 가까이 쉬는 둘이 부비·핥아주기·킁킁·놀이·하악·싸움(먼지구름). 친구(관계 2단계)는 싸우지 않음, 처음 보는 까칠이+변덕/장난은 싸울 수 있음. 현재는 연출 전용(관계 점수·관찰 단서에는 미반영).
- DevConsole(F1)에 상호작용 강제 버튼(QA).

## 자유 행동 + 시설 왕복 버그 수정 (2026-10-18)
- **버그(캣타워 왔다갔다)**: 3초마다 시설 재결정 + 재사용 패널티(0.3)가 선호 보너스(0.5)보다 작아 같은 시설을 계속 다시 고름. 게다가 로직은 '이용'을 순간 이벤트로 처리하고 표현만 2.6초 왕복 → 핑퐁. 
  - 수정: 시설 이용을 상태로(Approach→Perched 9~15초→Dismount), 시설 점유(Use/Release), 재사용 패널티 1.0(≈1분 회피). 회귀 테스트 FacilityRepeatTests.
  - 표현: 걸어가서 웅크림→도약(포물선)→위에서 식빵/잠, 끝나면 내려다보고 뛰어내림. 창문은 아래에서 올려다보기(gaze), 장난감 바구니는 놀기.
- **자유 행동**: 식사 후엔 자리에 묶이지 않음. 쉬기 / 카페 아무 데나 걸어가 앉기·눕기·자기 / 혼자 놀기(덮치기·뒹굴기·기지개) / 자리로 돌아가기. 활발·장난·호기심은 더 돌아다니고 느긋·내향은 덜.
  - 고양이끼리 상호작용도 위치 무관: 멀리 있으면 활발한 쪽이 상대 옆으로 걸어가서 어울림. 쓰다듬기도 어디서든.
  - 자리는 계속 '그 고양이 자리'로 점유(주문·식사는 자리에서).
- 시설 관찰 서술은 도착 순간에 뜨도록 이동. 걷기 속도 2.5→1.6(걷기 클립 보폭과 맞춤).

## 가구 배치·밤 관찰 일지·플레이어 앞발·대장냥이 (2026-10-18)
- **머무는 시간**: 유지(짧아도 됨) — 손님 수는 식사 자리를 더 사서 늘리는 구조. (기획 확정)
- **가구 배치 모드**(HUD [배치]): 시간 정지 후 가구를 끌어서 이동, 0.1유닛 격자, 바닥/벽 영역 제한, 겹치면 원위치. 그 위의 고양이는 같이 이동. 위치는 세이브(PlacedFurnitureDTO.hasPos, starterSeatPos).
  - 주의: 창가석을 창에서 멀리 옮겨도 '창가' 태그는 유지됨(태그=가구 속성). 위치 기반 태그는 추후 결정.
- **플레이어 앞발 고해상도**(PawDrawing 60×88): 셰이딩·발가락·손목 털, 누르는 프레임, 젤리 면. 주방 1인칭에 적용.

- **대장냥이**: 첫 성격 내향(까망냥). 입장 시 50% 확률로, 밥 먹고 자기 자리에서 쉬는 고양이 자리를 뺏음(선호 좌석 우선). 도착하면 하악 → 상대는 움찔하고 비켜나 돌아다님. 본 적 있으면 도감 이름 옆 '(대장)'.
