# 02. 튜토리얼 · 온보딩 상세 스크립트 (개발용)

> **목표**: 첫 세션(약 10~15분) 안에 **"가설→가구구매→검증 성공"** 1사이클을 반드시 경험시킨다. 이게 실패하면 게임 전체가 실패한다.
> **원칙**: 정답(취향)을 직접 알려주지 않는다. **방향만** 유도한다. 강제 최소, 스킵 가능.
> **구현**: 단계별 `TutorialStep` 데이터. 조건 충족 시 다음 단계. 상태는 세이브(재진입 대응).

---

## A. 튜토리얼 상태 머신

```
Step0_Intro → Step1_Move → Step2_FirstCat → Step3_Observe → Step4_Settlement
  → Step5_Hint → Step6_Shop → Step7_NextDay → Step8_Discover → Step9_Free
```
각 스텝: `id / 트리거조건 / 표시텍스트 / 완료조건 / 강제여부(대부분 soft)`.

---

## B. 스텝별 상세

### Step0_Intro (게임 시작 직후)
- 텍스트 `tut.step0.narr.01`: "당신의 카페, 《여기까페냐옹》에 온 걸 환영해요."
- `tut.step0.narr.02`: "고양이 손님들이 하나둘 찾아올 거예요. 잘 지켜봐 주세요."
- 완료: 확인 클릭. 강제.

### Step1_Move (조작)
- `tut.step1.narr.01`: "WASD로 움직이고, 클릭으로 상호작용해요."
- 완료: 플레이어 3초 이동 or 아무 상호작용 1회. soft.

### Step2_FirstCat (치즈냥 등장 — 튜토리얼 고정)
- 스폰: **치즈냥 고정 첫 손님** (관찰 신호가 가장 뚜렷한 고양이).
- 카페 초기 상태: **창가석 없음** (일반석만). → 치즈냥이 fallback 착석하게 만듦.
- `tut.step2.narr.01`: "첫 손님이에요! 뭘 하는지 지켜보세요."
- 완료: 치즈냥 착석. soft.

### Step3_Observe (행동 관찰 강조)
- 치즈냥이 **일반석에서 창밖을 힐끔거리는** 특수 연출(fallback이지만 '창'을 그리워하는 힌트).
- `tut.step3.narr.01`: "치즈냥이 자꾸 창문 쪽을 보네요… 뭔가 아쉬운 걸까요?"
- (주의: "창가석을 좋아한다"고 말하지 않는다. "창문 쪽을 본다"는 관찰만.)
- 완료: 치즈냥 퇴장. 강제 진행.

### Step4_Settlement (첫 정산 — 관찰 카드)
- `tut.step4.narr.01`: "하루가 끝났어요. 오늘의 관찰을 정리해봐요."
- 관찰 카드에 치즈냥: [창밖을 바라봄 ×N], 좌석축 상태 `?` (fallback이라 미승격).
- `tut.step4.narr.02`: "아직 확실하지 않아요. '기록'은 더 지켜본 뒤에 할 수 있어요."
- 완료: 카드 확인. soft.

### Step5_Hint (방향 유도 — 정답 아님)
- `tut.step5.narr.01`: "치즈냥이 창문을 그리워하는 것 같지 않았나요?"
- `tut.step5.narr.02`: "카페를 바꾸면, 못 보던 행동을 볼 수 있을지도 몰라요."
- 완료: 상점 열기. soft. (첫 상점 진입 유도)

### Step6_Shop (첫 구매 — 창가석)
- 상점에 **창가석 강조 표시**(할인 or 튜토리얼 무료 쿠폰 1회).
- `tut.step6.narr.01`: "새로운 가구는 새로운 행동을 볼 기회예요."
- 완료: 창가석 구매·배치. 강제(진행 필수).

### Step7_NextDay (다음 날)
- `tut.step7.narr.01`: "내일 치즈냥이 다시 올까요? 지켜봐요."
- 재방문 롤 조작(치즈냥 확정 재방문 — 튜토리얼).
- 완료: 다음 날 시작.

### Step8_Discover (검증 성공 — 결정적 순간)
- 창가석 존재 → 치즈냥 **창가석 착석 + 창밖 응시(강한 단서)**.
- `tut.step8.narr.01`: "봐요! 치즈냥이 창가석에 앉았어요!"
- 반복 관찰로 좌석축 Confirmable(★) 도달 → 정산에서 기록.
- 기록 시 **발견 연출**(도감 ✓ + "치즈냥의 취향을 하나 알아냈어요!" + 보너스).
- `tut.step8.narr.02`: "이게 이 게임의 전부예요. 관찰하고, 바꾸고, 발견하는 것."
- 완료: 첫 Recorded(✓). 강제.

### Step9_Free (자유 플레이)
- `tut.step9.narr.01`: "이제 당신의 카페예요. 더 많은 고양이를 이해해보세요."
- 튜토리얼 종료 플래그 저장. 삼색냥·젖소냥 등 정상 등장 시작.

---

## C. 튜토리얼 안전장치
- **스킵**: 설정에서 "튜토리얼 스킵" 제공(리플레이어 배려).
- **재진입**: 각 스텝 완료 플래그 세이브 → 중간 종료 후 이어서.
- **소프트 유도**: Step2~5는 강제 아님(플레이어가 스스로 발견하면 자동 스킵).
- **하드 게이트**: Step6(첫 구매)·Step8(첫 발견)만 강제 — 핵심 재미 각인 보장.

---

## D. 개발 데이터 포맷
```csharp
[Serializable] public class TutorialStep {
  public string id;
  public string[] narrationKeys;
  public bool forced;
  public string completeCondition;   // enum/스크립트 훅
}
```
- 튜토리얼 진행: `SaveGame.tutorialStep:int` (완료 스텝 인덱스).
- Step2/Step7/Step8의 "고정 스폰·확정 재방문"은 `TutorialDirector`가 스포너/재방문에 오버라이드 주입.

---

## E. 성공 지표 (플레이테스트 측정)
- Step6 도달률(첫 구매 유도 성공) ≥ 90%
- Step8 도달률(첫 발견) ≥ 85%
- 튜토리얼 이탈률 ≤ 15%
- 이 지표 미달 시 힌트 강도·연출 조정.
