## B. 접근성 상세
### B.1 색약 모드
- 취향 상태 아이콘은 **색+모양 이중 인코딩** (? / … / ★ / ✓ — 색에만 의존 금지).
- 분위기 미터·만족 표정도 형태로 구분(😻/🙂/😾).
- 색약 모드 시 팔레트 대체(빨강-초록 대비 강화).

### B.2 텍스트 크기
- TMP 폰트 스케일 3단계. UI 레이아웃은 큰 텍스트에서도 안 깨지게 여백 확보.

### B.3 관찰 힌트 강도 (난이도 조절 = 접근성)
- **약**: 힌트 최소(하드코어 추리).
- **보통**: 기본(정체 시 방향 힌트).
- **강**: 자주 방향 힌트(캐주얼 — "이 고양이는 다른 환경을 좋아할지도").
- 취향 정답은 어느 강도에서도 직접 노출 안 함(핵심 재미 보호).

### B.4 조작 접근성
- 리바인딩(Input System). 마우스만으로도 플레이 가능(WASD 없이 클릭 이동 대안 검토).
- 시간 압박 없음(회전율 압박 제거 P7) — 그 자체가 접근성.
- 일시정지 언제나 가능.

### B.5 인지 접근성
- 수치 대신 서술/아이콘 → 부담 낮음.
- 실패 페널티 약함(단골 강등 없음, 힐링 톤).

## C. 구현
- `SettingsManager`(PlayerPrefs 래핑) + `OnSettingChanged` 이벤트.
- 색약: 팔레트 SO 스왑 or 셰이더 LUT.
- 텍스트 크기: TMP 글로벌 스케일.
- 힌트 강도: ObservationManager/힌트 UI가 값 참조.

## D. 미니멈 vs 나이스투해브
- **1.0 필수**: 볼륨·전체화면·해상도·언어·튜토리얼 스킵·색약 이중인코딩·힌트 강도.
- **포스트**: 풀 리바인딩·텍스트 크기 3단계·추가 색약 프리셋.
