# 05. 오디오 기획 (개발용)

> **톤**: 조용하고 따뜻한 힐링. 관찰에 집중되도록 방해 없는 앰비언스 중심.

## A. BGM
| id | 용도 | 분위기 | 길이/루프 |
|---|---|---|---|
| bgm_title | 타이틀 | 잔잔·설렘 | 60s 루프 |
| bgm_cafe_day | 카페 영업 | 편안·아늑, 저자극 | 120s 심리스 루프 |
| bgm_settlement | 정산·발견 | 뿌듯·따뜻 | 40s 루프 |

- 볼륨 기본: BGM 60%. 관찰 몰입 위해 과하지 않게.
- (포스트런치) 비/밤 전용 BGM.

## B. SFX
| id | 트리거 | 느낌 |
|---|---|---|
| sfx_click | UI 클릭 | 부드러운 탁 |
| sfx_buy | 가구 구매 | 딸랑(동전) |
| sfx_place | 가구 배치 | 톡 |
| sfx_order | 주문 발생 | 뿅 |
| sfx_serve | 서빙 완료 | 짤랑 |
| sfx_pay | 결제 | 캐시 |
| sfx_discover | **취향 발견 성공** | 반짝(가장 기분 좋은 소리 — 여기 공들임) |
| sfx_cat_happy | 만족 퇴장 | 골골/야옹 만족 |
| sfx_cat_meh | 보통 | 짧은 야옹 |
| sfx_cat_unhappy | 불만 | 낮은 야옹 |
| sfx_door | 입·퇴장 | 문 종소리 |

## C. 앰비언스
- `amb_cafe`: 작은 잡담·컵 소리 루프(볼륨 낮게, 활기 분위기 강할 때 살짝↑).

## D. 오디오 구현
- `AudioManager`(싱글턴): BGM 크로스페이드, SFX 풀링.
- 설정 볼륨 2채널(BGM/SFX) + 음소거.
- SFX는 이벤트 채널 구독(OnCatPaid→sfx_pay, OnPreferenceRecorded→sfx_discover 등).
- 포맷: OGG(용량). 로딩: Addressables 불필요(소규모) → Resources/직접참조.

## E. 오디오-이벤트 매핑
| 게임 이벤트 | 사운드 |
|---|---|
| OnPreferenceRecorded | sfx_discover + 정산 BGM 살짝 강조 |
| OnCatPaid | sfx_pay |
| OnCatLeft(만족≥70) | sfx_cat_happy |
| OnCatLeft(만족<40) | sfx_cat_unhappy |
| OnFurniturePlaced | sfx_place |
| 구매 | sfx_buy |
| 시간대 전환 | (선택) 미묘한 BGM 필터 변화 |
