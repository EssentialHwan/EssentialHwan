# 03. UI/UX 화면 명세 (개발용)

> **범위**: 1.0 UI 8종. 각 화면 = 레이아웃(텍스트 와이어프레임) + 요소 + 상호작용 + 데이터 바인딩 + 상태.
> **원칙**: 관찰 게임 — 화면은 "수치"보다 "행동/서술"을 크게. 취향은 도감에서만 아이콘(?/…/★/✓).
> **해상도**: 1920×1080 기준, 16:9 고정(레터박스 허용). UI Canvas Scaler = Scale With Screen Size.
> **입력**: 마우스 주도 + 키보드 단축키(문서 사양서 §38).

---

## 화면 1. 타이틀 (Title)
```
┌──────────────────────────────┐
│         여기까페냐옹          │  ← 로고(중앙 상단)
│                               │
│        [ 이어하기 ]           │  (세이브 있을 때만 활성)
│        [ 새 게임 ]            │
│        [ 설정 ]               │
│        [ 종료 ]               │
│                               │
│   v1.0        © 2025          │  (하단)
└──────────────────────────────┘
```
- 이어하기: SaveManager.HasSave() true면 활성. → 카페 로드.
- 새 게임: 세이브 있으면 덮어쓰기 확인 팝업.
- 배경: 카페 일러스트 + 고양이 1~2마리 아이들 애니(루프).

## 화면 2. 카페 (플레이 · 메인)
```
┌─[시계 🕐 아침][남은시간 ▓▓▓░] ─────[💰 300G]─┐
│                                              │
│         (카페 3D/2.5D 뷰 - 고양이·좌석)       │
│      🐱"창밖을 오래 본다"  ← 서술 말풍선       │
│                                              │
│ [주문티켓: 생선케이크 🐟]                     │
│                                              │
│ [🔍관찰 Tab] [🛒상점] [⚙일시정지 ESC]  손님3 │
└──────────────────────────────────────────────┘
```
- 상단: 시간대 아이콘 + 남은시간 바 + 골드. **만족도 수치 비표시.**
- 중앙: 카페 뷰. 고양이 위 서술 말풍선(BehaviorNarrationRelay).
- 하단: 주문 티켓(클릭→조리), 상점/관찰/일시정지 버튼, 현재 손님 수.
- 배속 토글: Space (1x/2x).
- 카메라: 마우스 휠 줌(관찰용), 드래그 팬.

## 화면 3. 영업준비 · 상점 (통합)
```
┌─ 영업 준비 ─────────────── [💰300G] ─┐
│ [탭: 가구] [탭: 메뉴]                 │
│ ┌─────────┐ ┌─────────┐ ┌─────────┐  │
│ │창가석    │ │캣타워    │ │쿠션      │  │
│ │200G      │ │400G      │ │200G      │  │
│ │"새 행동을│ │          │ │          │  │
│ │ 볼 기회" │ │[구매]    │ │[구매]    │  │
│ │[구매]    │ └─────────┘ └─────────┘  │
│ └─────────┘                            │
│                        [영업 시작 ▶]   │
└────────────────────────────────────────┘
```
- 가구 카드: 이름·가격·**가설 유도 카피**("새로운 행동을 볼 수도 있어요")·구매 버튼.
- 잔액 부족 시 구매 버튼 비활성 + 회색.
- 구매 즉시 배치 모드로(화면 4) or 자동 슬롯 배치(S1 단순).
- 영업 시작: 카페 화면으로.

## 화면 4. 가구 배치 (Placement)
```
┌─ 가구 배치 ──────────────────────────┐
│ ┌─그리드─────────────┐  [인벤토리]    │
│ │ ░ ░ ░ [창]░ ░       │  창가석 ×1     │
│ │ ░ [의]░ ░ ░ ░       │  쿠션 ×1       │
│ │ ░ ░ ░ ░ ░ ░         │               │
│ └────────────────────┘  분위기:       │
│  [R]회전 [Del]삭제       조용함 ▓▓▓    │
│                          [완료]        │
└────────────────────────────────────────┘
```
- 드래그 배치, R 회전, Del 삭제. 충돌/공간부족 시 빨간 표시.
- 우측 분위기 미터 실시간 프리뷰(꾸미기 감성).
- (S1은 자동 슬롯으로 단순화 가능 — 배치는 S3 폴리시.)

## 화면 5. 하루 정산 · 관찰 기록 (Settlement)
```
┌─ 오늘의 정산 ────────────────────────┐
│ 매출 580G  재료비 120G  순익 460G     │
│───────────────────────────────────────│
│ 오늘의 관찰                            │
│ ┌──────────────────────────────────┐  │
│ │ 🐱 치즈냥  성격: 느긋함 / ?        │  │
│ │ ✓ 창밖을 오래 봄  ✓ 생선케이크 완식│  │
│ │ 음식[★] 좌석[★] 시설[?]           │  │
│ │        [음식 기록] [좌석 기록]     │  │
│ └──────────────────────────────────┘  │
│                       [다음 날 ▶]      │
└────────────────────────────────────────┘
```
- 매출/원가/순익 요약.
- 고양이별 카드: 성격(1즉시/2관찰), 오늘 행동 요약, 3축 아이콘(?/…/★/✓).
- **[기록] 버튼은 ★(Confirmable)에서만 활성.** 클릭 시 발견 연출(문서 01/02).
- 다음 날: 재방문 롤 → 카페.

## 화면 6. 도감 (Catalog — Tab)
```
┌─ 관찰 도감 ───────── [발견 5/8] ──────┐
│ [🐱치즈냥][🐱삼색냥][🔒?][🔒?] ...    │
│───────────────────────────────────────│
│ 🐱 치즈냥          단골 ★★☆ (2단계)   │
│ 성격: 느긋함 / 식탐                    │
│ 음식: ✓ 생선케이크                     │
│ 좌석: ✓ 창가석                         │
│ 시설: … (관찰 중)                      │
│ 근거: "창밖을 오래 봄" "쿠션에서 잠"   │
│ 완성도: ███░ 66%                       │
└────────────────────────────────────────┘
```
- 좌: 고양이 목록(미발견은 🔒?).
- 우: 선택 고양이 카드. 성격/3축/근거 단서/단골 뱃지/완성도.
- 필터: 발견/단골/미완성.
- **Truth 미접근 — ObservationRecord만 렌더.**

```

│ [화면] 전체화면 ☑  해상도 [1920×1080▾] │
│ [오디오] BGM ▓▓▓░  SFX ▓▓▓▓  음소거 ☐ │
│ [게임] 배속 기본 [1x▾]  튜토리얼 [스킵]│
│ [언어] [한국어 ▾] (English)            │
│ [접근성] 색약모드 ☐  텍스트크기 [보통▾]│
│ [데이터] 세이브 삭제  크레딧            │
│                          [닫기]        │
└────────────────────────────────────────┘
```

## 화면 8. 일시정지 (Pause — ESC)
```
┌─ 일시정지 ─┐
│ [계속하기]  │
│ [설정]      │
│ [도감]      │
│ [타이틀로]  │  (진행 저장 확인)
└─────────────┘
```

## UI 상태·전이표
| From | 액션 | To |
|---|---|---|
| Title | 새게임/이어하기 | Cafe(영업준비) |
| 영업준비 | 영업시작 | Cafe(플레이) |
| Cafe | 상점 | 영업준비·상점 |
| Cafe | 영업종료(자동) | Settlement |
| Settlement | 다음날 | Cafe(영업준비) |
| 어디서나 | Tab | Catalog |
| 어디서나 | ESC | Pause |

## 개발 참고
- 씬 전환 대신 **UI 패널 활성/비활성**(사양서 §37, 로딩 최소).
- 폰트: 한/영 지원 폰트 1개(예: 나눔/Noto). TMP.
- 모든 표시 텍스트는 로컬라이즈 키(문서 06).
- 관찰 게임 UX 핵심: **수치 숨김, 서술·아이콘 노출**.
