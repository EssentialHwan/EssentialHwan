# 04. 아트 · 사운드 에셋 목록 (1인+AI 제작용)

> **목적**: 출시에 필요한 최소 에셋을 전부 나열 + AI/에셋스토어 조달 전략 + 스타일 가이드.
> **원칙**: "적게, 일관되게." 스타일 통일이 물량보다 중요. 재사용·팔레트 스왑 적극 활용.
> **스타일 확정**: 아기자기한 2D 탑다운/2.5D, 파스텔 따뜻한 색감, 두꺼운 아웃라인 없는 소프트 셰이딩.

---

## A. 아트 에셋 목록

### A.1 고양이 (8종) — 최우선
| 항목 | 수량 | 비고 |
|---|---|---|
| 고양이 스프라이트/모델 | 8종 | 팔레트·무늬로 차별화(치즈/삼색/젖소/까망/턱시도/고등어/샴/회색) |
| 공용 애니메이션 | 종당 재사용 | walk / sit / eat / sleep / play / idle(꼬리흔들) = **6모션** |
| 감정 아이콘 | 3종 | 😻만족 / 🙂보통 / 😾불만 (말풍선용) |

> **절감 전략**: 8마리는 **같은 리그/애니**를 공유하고 텍스처(무늬·색)만 교체. 애니는 한 번만 제작.

### A.2 가구 (18종)
| 분류 | 항목 |
|---|---|
| 좌석 6 | 일반석·창가석·구석석·2인석·소파·바테이블 |
| 시설 6 | 캣타워·쿠션·장난감바구니·스크래처·화분·창문 |
| 장식 6 | 벽시계·액자·러그·조명·커튼·화병 |
| 상태 | 각 가구 정적 스프라이트 + (시설)이용 시 오버레이 |

### A.3 환경/배경
- 카페 바닥·벽 타일셋 (3레벨 확장분: 소/중/대)
- 입구/카운터/조리대
- 창문 너머 배경 (낮 1종; 비/밤은 포스트런치)

### A.4 UI
- 아이콘: 골드·시계·시간대(아침/점심/저녁)·관찰(돋보기)·상점·설정·별(★)·체크(✓)·물음표(?)·자물쇠
- 프레임/버튼/패널 9-slice 세트 1벌
- 도감 카드 프레임, 만족 표정 3종
- 로고 (타이틀)

### A.5 이펙트
- 발견 성공 연출(반짝임 파티클 1종 — 여기만 공들임)
- 착석/이용 소형 이펙트(먼지·하트)

## B. AI 생성 프롬프트 (예시 — 스타일 통일용 시드/키워드)

> 이미지 생성 AI 사용 시 **동일 스타일 앵커**를 모든 프롬프트에 붙인다.
> 공통 앵커: `cozy 2D game art, soft pastel palette, warm lighting, flat soft shading, no harsh outline, top-down cat cafe, cute, consistent style`

- 고양이(치즈냥): `{앵커}, orange tabby cat sitting, simple cute mascot, side view, transparent background, sprite`
- 창가석: `{앵커}, cozy window seat furniture for cats, isometric, transparent background, game asset`
- 카페 바닥 타일: `{앵커}, seamless wooden cafe floor tile, top-down, tileable`
- UI 아이콘 세트: `{앵커}, flat ui icon set, coin/clock/magnifier/star/checkmark, minimal, single color friendly`

> **주의**: AI 생성물은 스타일 편차가 크므로 (1) 시드 고정 (2) 후보정(색 통일·크기 정규화) (3) 한 도구로 통일. 라이선스/약관 확인 필수(상업 사용 가능 여부).

## C. 에셋스토어 조달 (대안/보완)
- Unity Asset Store에서 "cat / cafe / cozy" 스타일 팩 1개를 **베이스로 통일**하는 것이 AI 혼합보다 안전할 수 있음.
- 폰트: Noto Sans KR + Latin (무료, 한/영). TMP 임포트.
- 파티클: Unity 기본 + 무료 팩.
