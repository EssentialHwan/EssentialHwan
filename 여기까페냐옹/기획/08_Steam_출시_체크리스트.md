# 08. Steam 출시 체크리스트 (1인 개발자용)

> **목표**: 실제로 Steam에 게임을 올리기까지의 실무 단계. 개발 외 "출시 작업"을 빠짐없이.

## A. 사전 준비 (개발 병행)
- [ ] Steamworks 파트너 등록 (Steam Direct 수수료 $100/앱, 매출로 회수)
- [ ] 세금/은행 정보 등록 (Steamworks)
- [ ] 앱 ID 발급, 스토어 페이지 초안 생성
- [ ] 게임 이름 상표 충돌 확인(《여기까페냐옹》 / 영문명 확정: *Here, Cat Cafe* 등 검토)

## B. 스토어 페이지 자산
- [ ] 헤더 캡슐 (460×215) / 소형 캡슐 (231×87) / 메인 캡슐 (616×353)
- [ ] 스크린샷 5장 이상 (관찰→발견 순간 강조)
- [ ] 트레일러 (30~60초: 관찰→가구구매→행동변화→발견 루프 보여주기)
- [ ] 짧은 설명 + 상세 설명 (관찰·추리 훅 강조, "귀여운 카페 이상")
- [ ] 태그: Cozy, Cats, Simulation, Management, Singleplayer, Cute, Relaxing
- [ ] 시스템 요구사양 명시

## C. Steamworks 기능 통합 (1.0 최소)
- [ ] Steam 클라우드 세이브 (단일 오토세이브 파일 동기화)
- [ ] (선택/포스트) 도전과제 소수: 첫 발견 / 단골 1호 / 8마리 전원 발견 / 도감 100%
- [ ] Steam Input 기본 대응 (키보드/마우스 + 컨트롤러 선택)
- [ ] 언어: 한국어/영어 스토어·게임 내 표기

## D. 빌드/기술
- [ ] Windows 64-bit 빌드 (1.0 우선 플랫폼)
- [ ] 빌드 크기 최적화 (텍스처 압축, 미사용 에셋 제거)
- [ ] 시작~플레이 크래시 0 (스모크 테스트)
- [ ] 세이브 손상 방지 검증 (임시파일 교체, 버전 필드)
- [ ] 프레임: 저사양 노트북 60fps 목표(2D/2.5D라 여유)
- [ ] Steam 빌드 업로드 (SteamPipe / depot 설정)

## E. QA (문서 QA_TRACKING + 추가)
- [ ] T1~T22 전 항목 통과 (자동 16 + PlayMode/수동 나머지)
- [ ] 튜토리얼 완주율 플레이테스트 ≥ 85% (문서 02 지표)
- [ ] 3~5명 외부 플레이테스트 (핵심 재미 검증: "가구 사서 확인해볼래?")
- [ ] 로컬라이즈 검수 (영어 자연스러움)
- [ ] 긴 세션 안정성 (30일차 플레이 세이브·성능)

## F. 법무/정책
- [ ] 사용 에셋 상업 라이선스 확인 (AI 생성물 약관, 에셋스토어, 폰트, 오디오)
- [ ] 크레딧 화면 (에셋·도구 출처)
- [ ] 개인정보/데이터: 로컬 세이브만 → 수집 없음 명시

## G. 마케팅 (최소)
- [ ] 위시리스트 캠페인 (출시 전 스토어 페이지 공개 + 트레일러)
- [ ] 데모 빌드 (튜토리얼~첫 발견까지) — Steam Next Fest 참가 검토
- [ ] SNS/커뮤니티 GIF (발견 순간 = 가장 공유될 클립)
- [ ] 프레스킷 (스크린샷·로고·설명)

## H. 출시 D-Day
- [ ] 가격 책정 (인디 코지겜: $7.99~$14.99 검토)
- [ ] 출시 할인 (10~15%)
- [ ] 릴리스 노트 / 알려진 이슈 목록
- [ ] 출시 후 핫픽스 파이프라인 (크래시·세이브 이슈 우선)

## I. 출시 후 (포스트런치)
- [ ] 피드백 수집 → 밸런스 패치
- [ ] 확장: 관계 시스템 / 일일 상황 / 고양이 추가 / 시즌 / 도전과제
- [ ] 다국어 확장 (일/중)

## J. "출시 최소 기준" (이것만 되면 낼 수 있다)
1. 튜토리얼~자유플레이 크래시 없이 완주
2. 8마리 전원 취향 발견 가능 + 도감 완성 가능
3. 세이브/로드 안정
4. 한/영 표기
5. 스토어 페이지 + 트레일러
6. 외부 테스터가 "관찰이 재밌다"고 반응
