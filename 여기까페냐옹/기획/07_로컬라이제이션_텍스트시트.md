# 07. 로컬라이제이션 텍스트 시트 (한/영)

> **범위**: 1.0 = 한국어(기본) + 영어. Steam 도달을 위해 영어 필수.
> **구현**: CSV → Unity Localization(또는 자체 Dictionary). 키 기반. `{name}` 등 토큰 런타임 치환.
> **관리**: 아래 표를 `Assets/Localization/strings.csv`로 이관. 키 중복 금지.

## A. CSV 스키마

## F. 내러티브(문서 01) 키
> 에피소드·나레이션·서술 텍스트는 문서 01의 키를 그대로 CSV에 ko/en 두 열로 옮긴다. 영어는 톤 유지하며 자연스럽게 의역(직역 금지).

## G. 구현 규칙
- 미번역 키: 폴백 = ko 표시 + 콘솔 경고.
- 토큰: `{name}`, `{n}`, `{s}`, `{a}`, `{b}` 런타임 치환.
- 폰트: 한/영 동시 지원(Noto). 중국어/일본어는 포스트런치 시 폰트·CSV 열만 추가.
