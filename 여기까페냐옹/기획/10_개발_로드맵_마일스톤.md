# 10. 개발 로드맵 · 마일스톤 (출시까지)

> **목표**: 《여기까페냐옹》을 실제로 Steam에 출시한다.
> **원칙**: 게이트 기반. 각 마일스톤은 "다음으로 넘어가도 되는가?"를 판정하는 검문소. 특히 **M2 게이트(관찰 재미)** 미통과 시 이후 전면 중단·재설계.
> **주의**: 절대 기간(주/개월)은 개발자 여건에 따라 다르므로 **순서·게이트·산출물**로 정의. 각자 페이스로 채운다.

---

## 마일스톤 개요
```
M0 기반 → M1 코어 슬라이스 → [M2 재미 게이트] → M3 경영 → M4 콘텐츠
   → M5 폴리시 → M6 베타/QA → M7 스토어/출시 → (M8 포스트런치)
```

## M2. ★재미 게이트 (Core Fun Gate) — 가장 중요
- [ ] 3~5명 외부 플레이테스트 (임시 아트라도 무방)
- [ ] 측정: 관찰 여부 / 가설 발화 / **"가구 사서 확인해볼래" 발화** / 발견 만족 / 도감 열람
- [ ] 튜토리얼 완주율·첫 발견 도달률 (문서 02 지표)
- **PASS 기준**: 다수가 "관찰→추론→변경→발견"을 재밌어하고 스스로 반복.
- **FAIL 시**: M3 이후 전면 중단. 단서 연출·힌트·난이도 재설계 후 M2 재시도.
- **이 게이트를 통과해야만 나머지 투자가 정당화된다.**
