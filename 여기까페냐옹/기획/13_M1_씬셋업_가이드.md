# 13. M1 Unity 씬 셋업 가이드 (개발자 실행 매뉴얼)

> **목적**: 코드·데이터가 준비된 상태에서, Unity 에디터를 열고 **관찰 루프가 도는 씬**을 만드는 최단 경로.
> **전제**: `UnityProject/`를 Unity(2022 LTS+)로 열었고 컴파일 에러 0.

---

## 0. 사전 확인
- [ ] `Window ▸ Package Manager`에서 **Input System**, **AI Navigation(NavMesh)**, **TextMeshPro**, **Test Framework** 설치
- [ ] `Edit ▸ Project Settings ▸ Player`: Active Input Handling = Input System (또는 Both)
- [ ] 컴파일 에러 없음 확인 (콘솔)

## 1. 콘텐츠 에셋 생성 (원클릭)
- [ ] 상단 메뉴 **여기까페냐옹 ▸ 1.0 콘텐츠 에셋 생성** 클릭
- [ ] 생성 확인: `Assets/Data/Cats`(8), `Menus`(8), `Furniture`(17), `Events`(8), `Config/CafeLevels`
- [ ] `Assets/Data/` 우클릭 ▸ Create ▸ YeogiCafe ▸ **BalanceConfig** 1개 생성

## 2. 로컬라이즈 준비
- [ ] `Assets/Localization/strings.csv`를 **`Assets/Resources/strings.csv`** 로 복사(런타임 로드용)
  - (또는 게임 시작 시 `L.Load(csv.text)` 직접 호출)

## 3. 씬 구성
- [ ] 새 씬 `Assets/Scenes/Cafe.unity` 생성
- [ ] 빈 GameObject `[GameRoot]` 생성 → `S1Bootstrap` 컴포넌트 추가
- [ ] 카메라: 탑다운/약간 기울인 뷰. 마우스 휠 줌 스크립트(선택)
- [ ] 바닥: Plane/타일 + **NavMesh Bake**(AI Navigation) — 고양이 이동 경로
- [ ] 입구 위치: 빈 GameObject `Entrance` → `CafeContext.entrance`에 연결

### 좌석 배치
- [ ] 좌석 GameObject 3~4개 생성, 각각 `SeatBehaviour` + `source`에 좌석 FurnitureData(일반석 등) 연결
- [ ] (S1은 `S1Bootstrap.starterSeats`에 일반석 SO만 넣어도 자동 등록)

## 4. S1Bootstrap 인스펙터 연결
- [ ] `balance` ← BalanceConfig
- [ ] `starterCats` ← 치즈냥/삼색냥/젖소냥 (S1 고정 큐)
- [ ] `allCats` ← 8마리 전체 (해금 필터; S1엔 비워도 됨)
- [ ] `starterMenus` ← 생선케이크/딸기파르페/참치샌드/우유
- [ ] `starterSeats` ← 일반석
- [ ] `windowSeatData` ← 창가석 (상점 구매 대상)
- [ ] `cafeLevelConfig` ← CafeLevels
- [ ] 매니저 필드는 **비워두면 자동 생성**(EnsureManagers)

## 5. 최소 UI (디버그 수준으로 시작)
- [ ] Canvas + 정산 패널: 고양이별 관찰 카드(ObservationCardModel 렌더) + [기록] 버튼
- [ ] 상점 버튼 → `S1Bootstrap.BuyWindowSeat()` 호출
- [ ] 서술 말풍선: `BehaviorNarrationRelay.OnNarration` 구독 → TMP 텍스트
- [ ] 골드/시간대 표시(EconomyManager.OnGoldChanged, DayManager)

## 6. 첫 실행 (DoD 검증)
- [ ] Play → 치즈냥 스폰 → 일반석 착석(창가석 없으니 fallback) → 정산에서 좌석 `?` 확인
- [ ] 상점에서 창가석 구매 → 다음날 → 치즈냥 창가석 착석 + "창밖을 오래 본다"
- [ ] 반복 → 정산에서 좌석 ★ → [기록] → 도감 ✓ + 발견 연출
- [ ] 게임 종료 → 재실행 → 기록 유지
- [ ] `F1` DevConsole로 골드/배속 치트하며 빠르게 검증

## 7. NavMesh 이동 전환(선택)
- [ ] 고양이 프리팹에 `NavMeshAgent` + `NavMeshCatMover` 추가
- [ ] CatManager가 `GetComponent<ICatMover>()`로 자동 사용(SimpleLerp 대신)

## 8. M2 재미 게이트 준비
- [ ] 임시 아트라도 관찰이 "읽히는지" 확인
- [ ] 3~5명에게 플레이시키고 **"가구 사서 확인해볼래?"** 발화 관찰
- [ ] 문서 02 지표(튜토 완주율·첫 발견 도달률) 측정

## 트러블슈팅
| 증상 | 원인/해결 |
|---|---|
| 고양이가 안 움직임 | NavMesh 미베이크 or Mover 미부착 → SimpleLerpMover 자동부착 확인 |
| 좌석에 안 앉음 | SeatBehaviour.source 미연결 or CafeContext 미등록 |
| 관찰 카드 비어있음 | ObservationManager 이벤트 구독 확인, RecordClue 호출 로그 |
| 로컬라이즈 키 그대로 표시 | strings.csv를 Resources로 복사했는지 |
| 저장 안 됨 | 정산 완료 시 SaveManager.Save 호출 경로 확인 |

## 참고: 실행 시 자동 동작하는 것 (코드 완비)
- 고양이 스폰·좌석/음식/시설 선택·fallback·관찰 단서 기록
- 4단계 추론 승격·정산 승급·재방문 롤·단골·에피소드·성장·해금 필터
- 분위기 계산(승수는 BalanceConfig.atmosphereAffectsSatisfaction로 토글)
