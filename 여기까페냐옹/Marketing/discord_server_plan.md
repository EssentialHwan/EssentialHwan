# 디스코드 서버 구성안 (v1, 2026-10-26)

> 목적 두 가지: ① 친구·플레이테스터 피드백을 한곳에 모으기 ② 상점 페이지 공개 때 "위시리스트 눌러 주세요"를 부탁할 곳.
> 처음엔 작게. 사람이 적은데 채널이 많으면 텅 빈 느낌이 난다 → **채널 8개로 시작**.

## 서버 이름 · 아이콘
- 이름: **Wintery Studio** (게임이 늘어도 그대로 쓰기) — 게임 채널 묶음 이름을 `여기카페냐옹 · Purrsonal Taste`로
- 아이콘: 스튜디오 로고 아이콘(`Marketing/studio_logo/` 의 icon 파일)
- 배너(부스트 시): 캡슐 헤더 이미지

## 역할
- `@개발자` (형) · `@테스터` (빌드 받은 친구) · `@냥집사` (기본 역할, #규칙에서 🐾 반응으로 받기)
- 테스터만 보이는 `#테스트-빌드` 채널은 친구 배포 시작할 때 만들기

## #규칙 고정 글 (붙여 넣기용)
```
🐾 여기카페냐옹 · Wintery Studio 디스코드에 오신 걸 환영해요!
1. 서로 다정하게 — 사람에게도, 고양이에게도.
2. 스포일러(고양이 취향 정답)는 ||스포일러|| 처리해 주세요.
3. 버그는 #버그-bugs 에 양식대로 남겨 주시면 정말 큰 도움이 돼요.
4. 홍보·광고 글은 삭제될 수 있어요.
5. 아래 🐾 를 누르면 @냥집사 역할을 받고 모든 채널이 열려요.
```

## #버그-bugs 고정 양식
```
[버그 신고 양식]
- 몇 일차 / 시간대(아침·점심·저녁·밤):
- 무엇을 하다가:
- 무슨 일이 생겼나요:
- 다시 해도 똑같이 생기나요? (예/아니오/모름)
- 스크린샷 또는 영상 (있으면)
- 세이브 파일: 설정 → 저장 폴더 열기에서 찾을 수 있어요 (요청할 때만)
```

## 운영 규칙(형용)
- 공지는 짧게, 이미지 한 장 꼭. 주 1회 이상 #개발일지 (위시리스트 노출의 다음 요소 = 개발자 활동)
- 피드백엔 24시간 안에 이모지라도 반응 → "듣고 있다" 느낌이 사람을 남게 함
- 상점 페이지 열리는 날: @everyone 1회만 → "위시리스트 눌러 주시면 정말 큰 힘이 됩니다" (디스코드에선 위시 부탁 OK)
